# ToDo List

Ввеб-приложение для создания и управления задачами.

## Возможности

- добавление задач с названием, необязательными описанием и датой;
- редактирование и удаление задач;
- отметка выполненных задач;
- поиск по названию;
- сортировка по дате;
- сортировка и фильтрация по статусу;
- выделение задач по выбранной дате;
- изменение порядка через drag-and-drop;
- сохранение задач и их порядка в `localStorage`;
- адаптивное отображение на мобильных устройствах.
